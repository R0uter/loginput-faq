# 界面功能简述（Android）

落格输入法 Android 版是专为 Android 平台打造的高性能中文输入法，深度继承了落格输入法在双拼、辅码、自定义码表以及点划引导方面的核心优势，同时结合现代 Android 系统的设计语言（Material You / Material Design 3）与交互特性进行了全方位优化。

不论你使用的是全拼、双拼（小鹤、自然码等各类方案），还是五笔、郑码、仓颉等传统形码与音形码，亦或是 26 键、9 键九宫格、14 键双键布局，落格输入法 Android 版都能为你带来一致、流畅且高度可定制的打字体验。

* **本地轻量级 AI 动态候选**：业内领先的本地离线 AI 模型，结合输入上下文动态智能排序，无需联网，隐私零泄露；
* **完整的键盘布局矩阵**：标准 26 键、27 键、九宫格（9 键）、双键键盘（14 键）、落格十七、Dvorak、Colemak、Workman 等，永久免费开放切换；
* **音节与快捷侧栏**：九宫格与 14 键双键模式支持拼音音节选择侧栏与快捷标点符号侧栏；
* **硬件级安全的剪贴板历史**：磁盘数据使用 AES-GCM 高度加密，密钥保存在 Android Keystore 硬件安全芯片中，重启后安全保留，并提供“粘贴后即清空系统剪贴板”的防偷窥保护机制；
* **大屏与平板体验优化**：原生支持自由缩放、任意拖动的悬浮键盘，以及左手/右手无级调节的单手模式；
* **深度无障碍适配**：完美适配 Android TalkBack 旁白系统与 ExploreByTouchHelper，内置“落格解释库”与“经典解释库”；
* **跨平台对数云生态**：支持云端浏览、下载与分享主码表、辅码、双拼方案、点划配置、提示皮肤、背景图片与扩展词库。

本章节将为你系统介绍落格输入法 Android 版的主界面设置、系统功能、对数云以及各类辅助工具的使用方法。
