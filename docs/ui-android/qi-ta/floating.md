# 悬浮键盘与快捷面板

落格输入法 Android 版针对平板电脑、折叠屏设备以及大屏手机的日常单手与多任务操作，提供了高度灵活的交互形态与快捷工具系统。

## 悬浮键盘

悬浮键盘将输入法从传统的屏幕底部吸附形态解放出来，化身为一个可在屏幕任意位置自由移动的精致浮窗：

* **自由拖拽**：按住悬浮键盘顶部的拖动手柄，即可将键盘随心拖拽至屏幕任意合适位置，避免遮挡聊天或视频界面；
* **尺寸微调**：支持根据屏幕分辨率缩放键盘大小；
* **半透明视图**：悬浮模式下键盘具备通透的视效，既不阻挡下层应用内容，又保证按键清晰可辨；
* **快速进入/退出**：你可以通过长按键盘快捷工具面板中的“悬浮键盘”图标一键切换进入或退出悬浮状态。

## 单手模式

在大屏手机单手操作时，拇指往往难以触及屏幕另一侧的键位：

* **左右手快速靠边**：支持一键将键盘向左或向右靠齐；
* **无级宽度微调**：支持在屏幕宽度的 40% 到 90% 之间调节键盘宽度与比例；
* **专属独立布局**：可以在“界面设置”中为单手模式指定单独的键盘布局（如单手时切换为九宫格或双键键盘，双手全屏时恢复 26 键）。

## 键盘长按快捷工具面板

在键盘上长按特定按键（需在功能设置中开启“长按键盘工具面板”），即可呼出功能强悍的快捷面板。面板以多标签卡片形式汇聚了多项实用功能：

1. **快捷设置面板（Quick Settings）**：
   * 快速开关悬浮键盘模式；
   * 快速切换单手模式（左手/右手/全宽）；
   * 一键切换纯英文输入模式；
   * 一键切换繁体/简体输入；
   * 实时微调当前键盘高度。
2. **安全剪贴板历史（Clipboard History）**：
   * 直观浏览最近复制的多条历史记录；
   * 点击任意条目即时上屏；
   * 支持一键清空全部历史记录。
3. **大爆炸分词（Boom View）**：
   * 智能提取刚刚输入或复制的长句内容，并按照汉语语法将其“炸开”为独立的词语和字块；
   * 点击词块自由勾选并按序组合上屏，极大简化长句编辑与部分内容提取的操作成本。
4. **词典查词（Word Dictionary）**：
   * 快速检索字词的释义、读音与用法。
5. **按键统计（Key Logger）**：
   * 本地检视打字击键与输入字数统计数据。
