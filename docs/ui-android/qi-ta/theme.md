# 外观主题与语言

在主界面底栏点击“**其他**”，你可以对落格输入法主管理程序本身的主题风格与语言进行设定。

## 外观主题

主应用程序全面遵循 Material Design 3 设计规范：
* **跟随系统**：默认选项，根据 Android 系统当前的深色/浅色模式自适应切换界面配色；
* **浅色**：常驻明亮清爽的浅色界面；
* **深色**：常驻省电、低亮度的深色/暗黑夜间界面。

## 应用语言

落格输入法主界面支持多语言即时切换：
* **跟随系统**：根据手机系统的首选语言自动呈现；
* **简体中文**：强制以简体中文显示界面所有说明与设置项；
* **English**：为习惯英文界面的用户提供完整的英文本地化界面。
