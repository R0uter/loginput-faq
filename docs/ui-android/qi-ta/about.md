# 关于

在主界面底栏点击“**其他**”，选择“**关于**”，你可以查看落格输入法 Android 版的软件版本信息、隐私政策与法律声明。

## 应用信息与更新

* **版本号与构建号**：展示当前安装的落格输入法版本及运行环境；
* **检查更新**：点击可快速检查是否有新版本可用（Google Play 渠道或独立发布渠道）。

## 隐私政策

点击“**隐私政策**”可阅读落格输入法的完整隐私白皮书。落格输入法承诺：
* 输入法全程在设备本地离线执行输入处理；
* 不向任何远程服务器回传用户的打字内容、按键日志或剪贴板历史；
* 剪贴板历史本地存储采用高强度硬件加密（AES-GCM 与 Android Keystore）。

## 开源许可

落格输入法遵循开源社区精神，集成了众多卓越的开源项目组件。点击“**开源许可**”可查看所有依赖项的开源协议与版权信息（包括 OpenCC 中文繁简转换算法、dd-plist、FlexboxLayout 等）。
