# 对数云

对数云是落格输入法内建的跨平台配置分享与发现平台。你可以将它理解为一个专注输入法配置的公开分享中心。在 Android 版中，对数云不仅可以浏览和下载其他用户分享的优质配置，还可以无缝兼容与使用 iOS / macOS 用户分享的方案。

目前 Android 版对数云支持以下分类的配置浏览与一键安装：

* **主码表**：五笔、郑码、仓颉、小鹤音形等各流派自定义码表；
* **辅码码表**：小鹤形辅、自然码辅码等各类双拼与形辅配置；
* **点划引导**：用户分享的实用按键手势与宏命令布局；
* **双拼方案**：各类特色双拼方案定义；
* **映射提示皮肤**：按键上方显示的辅助字符或键位提示；
* **扩展词库**：各行业大词库、专有词汇表；
* **键盘背景**：适配键盘比例的高清壁纸与风格图片。

## 浏览与搜索

在主界面底栏点击“**对数云**”，即可看到分类列表。点击对应分类进入后，页面顶部提供了实时搜索框：

* 支持按配置名称、作者昵称或简介关键词进行即时检索；
* 列表展示了方案的下载热度、更新日期及核心说明。

## 查看详情与下载使用

点击任意你感兴趣的配置条目，即可进入配置详情页面：

1. **阅读说明**：查看分享者撰写的方案背景、键位规则或适用场景说明；
2. **下载安装**：点击页面中的“**下载**”按钮，落格输入法会自动将配置文件下载至本地并完成解析；
3. **启用配置**：下载完成后，你可以直接在对应的功能设置页面（如双拼方案选择、主码表选择、提示皮肤或键盘背景）中切换为刚刚下载的方案。

> 值得注意的是，如果你重复下载同一个同名配置，新下载的内容会自动覆盖本地旧版本。

## 隐私说明

对数云遵循落格输入法一贯的隐私至上原则。浏览和下载对数云中的内容无需注册账号，更无需授予任何个人身份权限，所有操作均安全匿名。
