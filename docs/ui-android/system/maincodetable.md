# 主码表

主码表是落格输入法专为纯形码、音形码（如五笔字型、郑码、仓颉、小鹤音形、两笔、山人全息等）用户提供的专业引擎。在该模式下，输入法将完全遵循码表的编码规则与字词映射关系。

在“**功能**”→“**输入模式设置**”的“**主码表**”区域，提供了极度专业和详尽的形码行为调节选项。

## 核心行为控制

### 四码唯一自动上屏

经典形码的核心输入体验：当键入达到四码且当前编码仅对应唯一的候选字词时，无需按空格键或数字键，该字词将**自动上屏**并清空编码。

### 码长限制

设置当前主码表的最大合法有效编码长度（通常为 4 码或 6 码），防止键入超出码长的无效字母。

### 空码清屏

当键入的编码在码表中不存在任何匹配候选（即“空码”）时，输入法会自动清空当前编码并发出提示，避免错误编码阻塞后续输入。

### 编码反查

开启后，在候选词条后方会同步显示其在主码表中的标准编码。对于正在背码、学码的新手或形码日常自查非常有帮助。

### 空码下滑

当遭遇空码时，自动将最后一次击键转化为向下滑动动作，触发预设的手势指令。

### 码表参与词频

决定主码表下的输入行为是否根据用户日常打字频次动态重排候选。纯粹追求“固顶、重码位置绝对不变”的资深五笔/形码用户建议关闭此项。

## 通配键模式（万能键）

* **通配模式**：支持设置特定按键（如 `z` 或 `?`）作为通配符，在忘记部分字根或字形时替代未知编码；
* **通配自动替换**：在候选字选定上屏后，自动用真实编码替代占位通配符；
* **通配仅查单字**：限制通配符仅在查询单字时生效，避免词库过大导致检索卡顿。

## 码表导入与管理

* **主码表选择**：从已安装的码表中快速切换；
* **导入自定义主码表**：点击“**导入自定义主码表…**”，支持导入外部标准纯文本码表格式（单字/词条与编码映射）；
* **编辑码表**：在手机端直接检视与快速编辑码表文件内容。
