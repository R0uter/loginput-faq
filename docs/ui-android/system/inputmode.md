# 输入模式

落格输入法 Android 版搭载了强劲且架构统一的输入引擎，支持全拼、双拼、形码主码表以及形辅（辅码）的无缝切换与协同输入。

在主界面底栏点击“**功能**”，选择“**输入模式设置**”，即可在此统一配置所有与打字模式相关的核心参数。

## 输入模式切换

落格输入法支持以下 5 种基础输入模式：

1. **全拼模式**：标准拼音输入，配合全拼引擎与纠错算法，打字容错率极高；
2. **双拼模式**：以声母加韵母双键拼写汉字的高效拼音模式；
3. **主码表模式**：纯形码或音形码模式（如五笔、郑码、仓颉、小鹤音形等），支持四码唯一自动上屏与固定码长；
4. **主码辅双拼**：以主码表作为主体输入，同时允许混用双拼编码，兼具速度与生僻字覆盖；
5. **主码辅全拼**：以主码表作为主体输入，当遇到遗忘编码的字词时，可直接用全拼补充输入。

## 全拼引擎设置

专为拼音爱好者打造的整句与智能纠错引擎：

### 全拼引擎开关

开启后启用针对长词和复杂整句优化的全拼引擎，提供高质量的词组匹配与流畅的分词处理。

### 拼音纠错等级

针对触屏手机虚拟键盘容易误触邻近按键的问题，落格输入法提供了智能纠错能力，支持多档容错调节：
* **关闭**：严格按照键入字母匹配，无任何纠错；
* **轻度**：仅修正极高概率的极相邻键位误触；
* **标准（推荐）**：平衡输入速度与容错率，智能识别并修正常见误触键位；
* **激进**：最大程度宽容手指误触，在快速盲打时容错效果显著。

### 自动纠错

允许输入法在检测到明显误触拼写时，自动将修正后的最可能候选推至首选位置。

## 拼音混输模式

在主码表或特定混合输入情境下，你可以指定拼音混输的具体策略，让拼音输入与码表输入互不干扰，平滑共存。
