# 扩展词库

扩展词库允许用户在不改动基础输入法词库与码表结构的前提下，为输入法额外注入海量的专业术语、行业词汇、成语俗语或流行文化网络用语。

在主界面底栏点击“**功能**”，选择“**扩展词库**”（或在对数云浏览“扩展词库”分类），即可管理扩展词库文件。

## 超大容量与高性能检索

落格输入法 Android 版基于优化的高性能本地检索算法构建，扩展词库具备惊人的吞吐与检索能力：
* **百万级条目支持**：本地扩展词库总量上限高达 **100 万条**；
* **单包大容量**：单个扩展词库安装包最高可容纳 **60 万条** 词条；
* 即使装载几十万级别的巨型词库，打字候选依然毫秒级响应，丝滑无卡顿。

## 启用与管理

* **启用扩展词库开关**：在“扩展词库”设置中开启总开关，导入的词条将自动参与候选检索；
* **本地导入**：支持从手机本地存储中选择标准文本格式的词库文件；
* **对数云获取**：可直接在对数云中浏览医疗医学、法律法规、古汉语诗词、计算机编程、地理地名等各类现成的优质扩展词库包，一键下载即刻启用。
