# 安全与隐私

落格输入法始终将用户的隐私安全置于首要位置。输入法处理的是用户最为私密的心声、密码与个人信息，因此落格输入法 Android 版在架构设计上坚持完全本地离线运行，绝不上传任何击键记录或隐私数据。

在“**功能**”底栏点击“**安全与隐私**”，你可以管理输入法的数据学习行为与高规格的安全防护选项。

## 数据与词库学习

### 快速用户词典

加速本地用户词典的词频与自造词学习。开启后，你频繁点选的常用候选词将以更快的速度跃升为首选项，显著缩短新词磨合周期。此功能完全在本地数据库运算，不涉及网络数据交换。

## 剪贴板安全体系

剪贴板是 Android 系统中最容易被第三方恶意应用在后台窥探隐私的重灾区。为此，落格输入法 Android 版构建了一整套高等级的安全剪贴板保护机制：

### 快速粘贴

开启后，当系统剪贴板存在新复制的文本内容时，键盘会在候选栏顶部自动呈现一条便捷卡片，轻点即可瞬间粘贴，无需在输入框中繁琐地长按呼出系统菜单。

### 硬件加密的剪贴板历史

开启后，落格输入法会在本地维护一个最近剪贴板内容的历史记录队列，方便多条文本循环复用：
* **硬件级高强度加密**：保存在磁盘上的剪贴板数据全部采用 **AES-GCM** 算法加密，解密密钥安全存储于 **Android Keystore** 硬件安全芯片中；
* **重启持久化**：即使手机关机重启，加密历史依然安全留存；
* **智能敏感信息过滤**：自动识别并跳过由密码管理器（如 1Password、Bitwarden）、验证码以及信用卡号等标记的敏感数据，绝不记录敏感隐私；
* **便捷访问与清空**：随时可通过长按键盘呼出的工具面板查阅历史条目、快速点选上屏或一键彻底清空。

### 剪贴板保护模式

这是一项极具安全价值的独创防护功能（需先开启剪贴板历史）：
* 开启后，每次通过落格输入法完成粘贴动作后，键盘会**立即自动清空 Android 系统的全局剪贴板**；
* 剪贴历史被完整隔离并保护在落格输入法加密沙盒内，用户只能通过键盘自身安全地复用历史；
* 任何试图在后台监听系统剪贴板的第三方流氓应用将只能读到空内容，彻底杜绝隐私泄露风险。
