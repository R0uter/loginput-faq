# 辅码

辅码（辅助码 / 形辅）是落格输入法最具标志性的核心特性之一。通过在拼音（双拼或全拼）编码之后附加汉字的字形笔画编码，能够极大程度消除同音字重码，实现“无需翻页、指哪打哪”的盲打体验。

在“**功能**”→“**输入模式设置**”中向下滚动至“**辅码**”区域，即可对辅码逻辑进行深度定制。

## 辅码选项设置

### 辅码范围

你可以决定辅码起作用的对象范围：
* **仅单字**：只有单字候选响应辅码筛选；
* **单字与词汇**：打出词语拼音后，输入该词中字词的形码同样可以精准过滤词汇候选。

### 辅码提示

控制候选栏中是否直观展示当前候选字所对应的辅码：
* 开启后，候选字词后方会附带辅码小标记，方便新手熟悉和记忆字根。

### 辅码首选后移

开启后，如果输入的辅码过滤出了新的候选词，原有未经辅码过滤的首选词会被顺延后移，确保匹配辅码的目标字跃居第一位。

### 辅码词汇优先

在同时命中单字与词汇时，优先将符合辅码的词语排在单字前面。

### 辅码下划线标记

在输入框或候选编码区，使用下划线（`_`）清晰标注辅码部分，与前面的拼音编码形成直观区分。

### 辅码参与词频

决定通过辅码筛选后点选的字词是否纳入用户的动态自造词与词频记忆库中。

## 方案管理与自定义码表

* **辅码方案选择**：快速选用主流辅码码表（如自然码形辅、小鹤形辅等）；
* **导入自定义辅码**：点击“**导入自定义辅码…**”，支持选择外部文本码表直接导入；
* **编辑辅码码表**：内置文本查看与编辑工具，可直接在手机端查看和修改辅码键位条目。
