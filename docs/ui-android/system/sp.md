# 双拼方案

双拼是将汉字拼音的声母与韵母分别映射到键盘的两个英文字母按键上，每个汉字只需击键两次即可完成编码的高效拼音输入方式。

落格输入法 Android 版不仅内置了市面上全部主流双拼方案，还支持导入、编辑以及在手机端直接创建自定义双拼方案。

## 方案选择

在“**功能**”→“**输入模式设置**”页面中，找到“**双拼方案**”部分：

* **内置主流方案**：小鹤双拼、自然码、微软双拼、搜狗双拼、紫光双拼、智能ABC、落格双拼 等；
* 点击下拉菜单即可即时切换，切换后键盘布局及候选映射立即生效。

## 导入自定义双拼方案

如果你使用的是小众或自行修改的双拼方案，你可以通过以下途径导入：

1. **导入本地文件**：点击“**导入自定义双拼方案…**”，从手机存储空间中选择方案文件（支持标准文本格式与 `.plist` 配置文件）；
2. **从对数云下载**：在“**对数云**”中浏览并下载其他用户分享的双拼方案，下载后系统会自动将其添加至可选列表。

## 创建与编辑方案

落格输入法 Android 版内置了原生的双拼方案可视化编辑器（`ShuangpinPlanEditor`）：

* **创建新方案**：点击“**创建新方案…**”，输入方案名称后，应用将呈现 26 个字母键位的声母与韵母映射分配表，逐一设定即可保存；
* **编辑现有方案**：点击“**编辑方案…**”，可在现有方案的基础上快速调整部分按键的声韵母映射，满足个性化按键偏好。
