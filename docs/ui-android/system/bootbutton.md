# 点划引导

点划引导是落格输入法最具特色的核心手势功能。通过在 26 个字母按键上快速向上轻扫（Swipe Up）、向下轻扫（Swipe Down）或长按（Long Press），你可以无需切换符号键盘或功能面板，瞬间完成各类高频输入与指令操作。

在主界面底栏点击“**功能**”，选择“**点划引导**”，即可查看当前点划方案、管理各方案列表或创建个性化点划映射。

## 默认点划功能

在默认预设点划方案中，上划多用于输入常用中文标点符号（如 `a` 上划输入叹号 `！`，`w` 上划输入问号 `？`），同时分配了多项强大的系统指令：

* **`u` 上划**：撤销上一次上屏的内容；
* **`f` 上划**：快速重复输入刚才上屏的内容；
* **`n` 上划**：快速将光标跳转到当前输入内容的末尾；
* **`e` 下划**：临时进入英文输入模式；
* **`p` 下划**：进入防记录的隐私模式；
* **`b` 下划**：呼出键盘快捷管理面板；
* **空置下划**：若按键未分配下划动作，默认下划将呼出表情与颜文字面板。

## 自定义点划配置

落格输入法 Android 版提供了完整的点划方案管理与可视化编辑器（`BootButtonSettings`）：

1. **多套方案并存**：你可以保存多套不同的点划配置文件，根据不同工作场景自由切换；
2. **可视化编辑键位**：点击任意配置进入编辑界面，可直观点击每个按键，分别配置其：
   * **上划内容**：可填入固定符号、常用文本短语或特殊功能宏；
   * **下划内容**：可填入文本或系统功能宏；
   * **长按动作**：分配长按专属内容；
3. **导入与导出**：支持将点划配置文件导出为 `.plist` 格式备份，或导入外部及对数云分享的点划方案。

## 宏与前缀匹配

* **点划宏**：点划内容不仅支持纯文本，更支持丰富的自动化宏命令（例如日期时间宏、剪贴板宏、模式切换宏等）；
* **前缀匹配**：你可以为同一按键设置前缀条件，根据输入框光标前的特定文字动态触发不同的点划内容。
