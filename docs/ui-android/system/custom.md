# 自定义编码

自定义编码（用户自定义短语/码表）允许你为日常高频使用的词汇、邮箱、收件地址、固定回复模板等内容分配专属的简短编码，打出编码即可立即候选上屏。

在主界面底栏点击“**功能**”，选择“**自定义编码**”，即可进入自定义编码管理系统。

## 基础条目管理

在自定义编码列表中，你可以直观查看所有已保存的编码映射关系（如 `yx` → `yourname@example.com`）：

* **添加新条目**：点击右上角菜单中的“**添加**”，输入所需的编码及对应的展开文本即可保存；
* **编辑与删除**：点击列表中的已有条目可随时修改编码或内容，亦可单个或批量删除。

## 批量导入与导出

* **文本批量导入**：支持将格式为 `编码\t文字` 或 `文字\t编码` 的纯文本文件批量导入到本地数据库中；
* **全量导出**：将当前全部自定义编码导出为标准文本文件，方便在电脑端整理或在多设备间同步。

## 导入通讯录联系人（特色功能）

落格输入法 Android 版独家提供了极为便捷的通讯录联系人导入功能：

* **一键提取联系人**：点击菜单中的“**导入联系人姓名**”或“**导入联系人电话**”；
* **自动生成编码**：系统会在本地将联系人姓名自动转换为对应的全拼或双拼编码，并将联系人的姓名或手机号码作为输出内容；
* 打字时只需键入朋友的名字拼音，即可直接在首选位置输出他的名字或手机号，告别频繁翻找通讯录复制号码的繁琐。
* **隐私保证**：通讯录解析完全在本地一次性完成，绝无任何网络上传。
